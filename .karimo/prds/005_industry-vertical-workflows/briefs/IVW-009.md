## Gotchas

- The `key` field `'Dental / Oral Health'` must match exactly what IVW-001 set in `app/dental/page.tsx` and `lib/diagnosticPrompts.ts`. Read those files first to confirm the exact string before writing.
- `daysInAR` in `kpiPanels` has `higherIsBetter: false` — lower days in AR is better. Handle this correctly in the report panel component (IVW-011).
- `noShowRate` also has `higherIsBetter: false`.
- The `hipaaNote` field is unique to dental — fitness.ts does not have this field. TypeScript will still be happy because `as const` infers the exact shape. Downstream code using `dentalConfig.hipaaNote` will need to handle the fact that `fitnessConfig.hipaaNote` is undefined — use optional chaining.
- The `recallOpportunityFormula` uses `providerCount` (number of dentists/hygienists), not patient count. This is different from the fitness formula which uses `memberCount`. The report panel (IVW-011) should document what inputs to request from the submission.
- The onboarding form's `hipaaAcknowledgment` field has `type: 'checkbox'` — IVW-011 will need to render this as a required checkbox, not a text input. The `label_text` property carries the legal language.
