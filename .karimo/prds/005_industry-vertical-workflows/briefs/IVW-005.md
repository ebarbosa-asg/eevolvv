## Gotchas

- The key string `'Fitness / Gym / Studio'` uses forward slashes and title case. Confirm the exact string from `lib/industries/fitness.ts` before typing it as the object key here — one wrong character breaks the lookup silently (falls to DEFAULT_CONTEXT with no error).
- The entry value is a raw string, not a TypeScript object. Every automation description, benchmark, and vocabulary note goes in the string. No TypeScript typing required inside the string.
- The `INDUSTRY_CONTEXT` object grows by 1 entry; the `getIndustryShortName` map grows by 1 entry. These are the only two changes to this file.
- Keep the existing `'Gym / Fitness / Wellness'` entry — it covers existing submissions that used that key. Removing it would break `buildSystemPrompt` for any archived submission with that industry value.
- The BASE_PROMPT at line 1 defines the output structure (BUSINESS SNAPSHOT, TOP AUTOMATION OPPORTUNITIES, etc.). The new fitness context entry does NOT override that structure — it supplements it. Claude will still follow the BASE_PROMPT sections but with fitness-specific vocabulary and benchmarks.
