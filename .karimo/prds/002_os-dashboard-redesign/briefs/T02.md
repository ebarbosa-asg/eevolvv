## Requirements

### File 1: `app/os/components/OSBreadcrumb.tsx`

Export a `OSBreadcrumb` component with this interface:

```tsx
type Crumb = { label: string; href?: string }
interface OSBreadcrumbProps { crumbs: Crumb[] }
```

Renders a horizontal breadcrumb trail:
- Font: JetBrains Mono, 11px, uppercase, 0.1em tracking
- Each crumb with an href is a `<Link>` with `color: rgba(250,247,240,0.45)` and no text decoration
- The last crumb (no href) is `color: var(--paper)`, no link
- Separator between crumbs: `/` at `opacity: 0.25`
- Container: `display: flex; align-items: center; gap: 8px; padding: 0 24px; height: 48px`
- The component should be `'use client'` (uses Next.js Link)

Example usage (from AgentBuilder breadcrumb pattern at lines 249–255 of AgentBuilder.tsx):
```tsx
<OSBreadcrumb crumbs={[
  { label: 'os', href: '/os' },
  { label: client.company, href: `/os/clients/${client.id}` },
  { label: agent.name },
]} />
```

### StagePipeline source

Copy exactly from HubClient.tsx lines 212–224:

```tsx
import { Fragment } from 'react'
const STAGES = ['diagnose', 'onboard', 'build', 'maintain'] as const

export function StagePipeline({ stage }: { stage: string }) {
  const active = STAGES.indexOf(stage as typeof STAGES[number])
  return (
    <div style={{ display: 'flex', gap: '4px', alignItems: 'center' }}>
      {STAGES.map((s, i) => (
        <Fragment key={s}>
          <div style={{ width: '7px', height: '7px', borderRadius: '50%', background: i <= active ? 'var(--accent)' : 'rgba(255,255,255,0.15)', flexShrink: 0 }} title={s} />
          {i < STAGES.length - 1 && <div style={{ width: '10px', height: '1px', background: i < active ? 'var(--accent)' : 'rgba(255,255,255,0.1)' }} />}
        </Fragment>
      ))}
    </div>
  )
}
```

### OSBreadcrumb — sticky vs embedded

`OSBreadcrumb` is NOT a sticky topbar. It will be used inside pages as an inline breadcrumb trail (T07, T08 use it to replace the topbar div in ClientWorkspace and AgentBuilder). It should not have `position: sticky`. The sticky behavior is already provided by the OSTopbar from T01.

Actually, looking at the usage in ClientWorkspace (lines 266–272) and AgentBuilder (lines 248–256), the breadcrumb IS rendered as a sticky topbar replacement. Those files render a full sticky `<div>` bar with the breadcrumb content. Make `OSBreadcrumb` a simple inline component — the calling page wraps it in a sticky container if needed.
