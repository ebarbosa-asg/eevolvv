## Objective

Upgrade the existing /os layout infrastructure to support per-section routing. The current `app/os/layout.tsx` delegates to `OSLayoutClient` which renders `OSSidebar` — a scroll-anchor sidebar that only works on the monolithic `/os` root. This task converts the sidebar to use route-based navigation links, adds an `OSTopbar` component, and ensures the shell works across all `/os/*` routes.

---

## Context

The current layout stack is:

```
app/os/layout.tsx          — server wrapper, injects LAYOUT_CSS, renders OSLayoutClient
app/os/OSLayoutClient.tsx  — 'use client', manages collapsed/isNarrow state, renders OSSidebar
app/os/OSSidebar.tsx       — 'use client', 383 lines, fixed-position sidebar
```

`OSSidebar.tsx` currently:
- Has a `SECTIONS` array with 9 anchor items (§00–§08)
- Uses `scrollTo(anchor)` to scroll within `/os` page — only works when `isOsRoot === true`
- Has a "Clients" section at the bottom fetching `/api/os/clients`
- Has a "Company tasks" section fetching `/api/os/company-tasks`
- Uses lucide-react `PanelLeftClose` / `PanelLeft` icons
- Is positioned `fixed` at `left: 0`, `width: 240px`
- Sidebar background: `linear-gradient(165deg, rgba(24,24,23,0.98)…)` — effectively bg-ink

There is NO `OSTopbar` component yet — it needs to be created.

The current `app/os/layout.tsx` has inline `LAYOUT_CSS` with `.os-layout`, `.os-sidebar-space`, `.os-main`, `.os-sidebar-overlay` classes.

`OSLayoutClient.tsx` manages:
- `collapsed` state (persisted to localStorage `os-sidebar-collapsed`)
- `isNarrow` state (matches `(max-width: 1024px)`)
- Keyboard `Esc` to collapse
- `OS_SIDEBAR_W = 240`

## Implementation Guidance

### Existing sidebar patterns to preserve

The sidebar already uses this active link style:
```tsx
borderLeft: pathname === `/os/clients/${c.id}` ? '3px solid var(--accent)' : '3px solid transparent',
background: pathname === `/os/clients/${c.id}` ? 'rgba(255,255,255,0.08)' : 'rgba(255,255,255,0.02)',
color: pathname === `/os/clients/${c.id}` ? 'var(--paper)' : 'rgba(250,247,240,0.55)',
```
Apply the same pattern to the new route-based nav items.

### Badge fetch pattern

The sidebar already fetches clients and tasks. Extend the same pattern:
```tsx
useEffect(() => {
  fetch('/api/os/agents').then(r => r.json()).then((d: AgentRow[]) => setAgentCount(d.length)).catch(() => {})
}, [])
```

### OSTopbar sign-out

```tsx
'use client'
import { signOut } from 'next-auth/react'

export function OSTopbar({ title }: { title: string }) {
  return (
    <div style={{ position: 'sticky', top: 0, zIndex: 50, background: 'rgba(20,20,19,0.95)', backdropFilter: 'blur(12px)', borderBottom: '1px solid rgba(255,255,255,0.07)', display: 'flex', alignItems: 'center', justifyContent: 'space-between', padding: '0 24px', height: '48px' }}>
      <span style={{ fontFamily: 'JetBrains Mono, monospace', fontSize: '11px', textTransform: 'uppercase', letterSpacing: '0.15em', color: 'var(--paper)' }}>{title}</span>
      <button onClick={() => signOut({ callbackUrl: '/' })} style={{ fontFamily: 'JetBrains Mono, monospace', fontSize: '11px', textTransform: 'uppercase', letterSpacing: '0.1em', color: 'rgba(250,247,240,0.45)', background: 'none', border: 'none', cursor: 'pointer' }}>sign out</button>
    </div>
  )
}
```

### Active route detection

```tsx
const pathname = usePathname()

function isActive(route: string): boolean {
  if (route === '/os') return pathname === '/os'
  return pathname === route || pathname.startsWith(route + '/')
}
```
