# Homepage Graphics Plan

## Goal

Keep the homepage short and free-report-centric. The page should be a simple sandwich:

1. Top: free diagnostic report invitation.
2. Middle: three capability graphics.
3. Bottom: free diagnostic report invitation plus $97 roadmap upgrade.

Do not add a standalone Volvv-E introduction section. Do not add fake live ops dashboards. Do not add large diagnostic report preview cards to the homepage.

Inputs to visualize:

- Calls
- Calendar
- CRM
- Tasks
- Docs
- Invoices
- Follow-up

- Operating hub

## Copy Rules

- Keep language concrete.
- Avoid "meet Volvv-E", "marks the free stuff", and mascot explanation copy.
